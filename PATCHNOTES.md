# FakeDeafen
## Version 1.0
This is the first official version of this plugin. It includes the basic features like setting a keybind to toggle fake deafen, fake mute or fake video.
# BigFileUpload
## Version 1.0
This is the first official version of this plugin. It allows the user to automatically upload large files to file hosting services like GoFile using their api. It also allows the user to use their specific account token for the chosen service in orded to save the uploaded files directly into their account.
# EncryptedText
## Version 1.0
This is the first official version of this plugin. It allows the user to send End-to-end Encrypted messages using the /e2ee command in any chat. The encyption key must be set in the plugin's settings. If any of the recipients have the same plugin installed, they will see the original message, provided they have the correct key set. If the reciepient doens't have the plugin installed, they can use the provided decryption tool, given they know the secret key that the original sender used.
