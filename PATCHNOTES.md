> [!NOTE]
> Plugins in their beta or with known bugs will still get installed on your client by the update script. If you do not wish to use them, just don't enable them from settings. They take up negligible space, not affecting you if you don't enable them. If you still do not wish to have them at all on your system, you will have to manually install the desired plugins, and manually update them, including all other plugins from this repo. 

# FakeDeafen
## Version 1.0
This is the first official version of this plugin. It includes the basic features like setting a keybind to toggle fake deafen, fake mute or fake video.
# BigFileUpload
## Version 1.0
This is the first official version of this plugin. It allows the user to automatically upload large files to file hosting services like GoFile using their API. It also allows the user to use their specific account token for the chosen service in order to save the uploaded files directly into their account.
# EncryptedText
## Version 1.0
This is the first official version of this plugin. It allows the user to send End-to-end Encrypted messages using the /e2ee command in any chat. The encryption key must be set in the plugin's settings. If any of the recipients have the same plugin installed, they will see the original message, provided they have the correct key set. If the recipient doesn't have the plugin installed, they can use the provided decryption tool, given they know the secret key that the original sender used.
# UserColors
## Version 0.1 :exclamation: This plugin is in Beta and may not work as intended.
This is the first official version of this plugin. It allows users to change the color of any user's username, overriding role colors. 
> [!NOTE]
> This plugin is client sided, meaning other people cannot see the colors that you set.
### :warning: Known bugs
* The plugin may not work outside of the chat window, meaning that a changed color may not be visible on the right side members panel.
# InvisibleDetector
## Version 0.1 :exclamation: This plugin is in Beta and may not work as intended.
This is the first official version of this plugin. It scans for actions like typing, sending a message, joining a voice, etc. and, if a user is set to invisible and triggers it, a visible sign will appear near their username. 
> [!NOTE]
> Since when a person is invisible, your client sees it as offline, someone who is not doing any action that your client can detect can't get detected.
### :warning: Known bugs
* Some triggers like joining a voice or a thread may not be detected.
